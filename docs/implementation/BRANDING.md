# Branding: app icon and start screen

Written 2026-10-30. Source images live in `design/icons/`: `icon_logo.png` (the rhea on green, 1087 × 1076)
and `icon_no_background.png` (the same head with the background removed, 1512 × 1512, transparent).

## Launcher icon

Generated by `make_icons.py` (kept in the session scratchpad; the recipe is below so it can be rebuilt with
Pillow in a minute). Everything is derived from `icon_no_background.png`:

| Resource | What | Sizes |
|---|---|---|
| `mipmap-*/ic_launcher_foreground.png` | Adaptive-icon foreground, 108 dp canvas. The head is cropped to its bounding box, scaled to 80 dp tall, centred, top at 24 dp, so it sits like a portrait and the neck runs out of the bottom of whatever mask the launcher uses. | 108 / 162 / 216 / 324 / 432 px |
| `values/ic_launcher_background.xml` | Background colour `#2A6A47` (sampled from the green in `icon_logo.png`; also exposed as `@color/brand_green`). | — |
| `mipmap-*/ic_launcher_monochrome.png` | Android 13 themed icon: the head's alpha as a white silhouette. | same |
| `mipmap-*/ic_launcher.png`, `ic_launcher_round.png` | Legacy icons for Android 7.0/7.1 (minSdk 24): the central 72 dp of the same composition, pre-masked as rounded square (18 % radius) and circle. | 48 / 72 / 96 / 144 / 192 px |
| `drawable-nodpi/brand_logo.png` | The head alone, 640 px tall, used in the app (`BrandMark`). | — |

`mipmap-anydpi-v26/ic_launcher.xml` (and `_round`) declare the three layers. The **launcher applies its own
mask** (circle, squircle, rounded square, teardrop); the safe zone is the central 66 dp circle, which is why
the head's eye and beak stay inside it and only the neck crosses the edge.

Rebuild recipe: crop to `getbbox()`, resize to 80 dp × density, paste at (centre, 24 dp × density) on a
transparent 108 dp canvas; legacy = composite on `#2A6A47`, crop the central 72 dp, mask.

## Start screen

One splash only, the system one (`Theme.Piyo.Starting`, parent `Theme.SplashScreen` from
`androidx.core:core-splashscreen`), redesigned 2026-10-31 after the owner rejected the green-on-green version:

- `windowSplashScreenBackground` = the app background (`#F7F8F5` light, `#0E1012` night), so the green logo
  circle is the only colour on screen.
- `windowSplashScreenAnimatedIcon` = `@mipmap/ic_launcher`: the OS draws the adaptive icon with the device's
  own mask (circle on Pixel, rounded square on MIUI, ...). This is why there is **no second, hand-drawn
  splash any more**: a Compose copy of the mark never matched the mask and size the launcher used, and the
  hand-over was a visible jump.
- Android 12+ (`values-v31`, `values-night-v31`): `android:windowSplashScreenBrandingImage` =
  `drawable-*/splash_branding.png`, 200 × 80 dp at the bottom: "piyo" in Sora Bold and the tagline on two
  lines, in the theme's ink/muted colours (light and night variants). Generated by `make_branding.py`
  (scratchpad; Sora variable font from google/fonts). Android 7–11 show the icon only.
- `MainActivity` keeps the splash up with `setKeepOnScreenCondition` until the dataset is open and the first
  route is decided (Inicio, first run or the thanks deep link), then fades it out over the first frame
  (220 ms, `setOnExitAnimationListener`). No artificial minimum: on the Xiaomi the splash lasts ~1.2 s, all
  of it dataset loading (2 MB JSON + 104k transfer links).

The old `SplashScreen` composable and `SplashRoute` were removed; `FirstLoadScreen` and `BrandMark` stay in
`ui/screens/SplashScreens.kt`.

## Using the brand elsewhere

Call `BrandMark(size)` (same file) for any place that shows the logo, instead of loading the PNG directly, so
it always looks like the launcher icon: head on green, circular.
