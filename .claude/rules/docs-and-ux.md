# Documentation and copy rules (all paths)

- Decisions and evidence live in `docs/implementation/`; update the relevant file in the same PR as
  the code (DATA_MODEL, CONTRIBUTIONS_DESIGN, PRIVACY, SETUP_AND_RUN, DEPENDENCIES).
- Public READMEs describe what exists and how to run it. No roadmap promises, no internal logs,
  no provider branding (see `docs/DATA_SOURCES.md`).
- UI copy: Spanish, Bolivian voseo, plain words, one idea per sentence. Fares in "Bs 3,50" format.
  Use "micro", "trufi", "recorrido", "ida/vuelta", "transbordo" consistently.
- Honest offline wording: say what needs a connection ("Buscar direcciones necesita internet").
- Screenshots for PRs come from a real device or emulator, never mocked.
